# Security Policy

## Reporting a vulnerability in Bastion

If you find a security issue in the Bastion installers, hook, templates, or a rule that would lead users to an insecure configuration, report it privately:

- Use **Security > Report a vulnerability** on this GitHub repository, or
- Email the maintainer listed on the GitHub profile.

Please do not open a public issue for security problems.

We aim to acknowledge reports within 3 business days and to publish a fix for confirmed issues within 30 days.

## Scope

- `scripts/install.sh`, `scripts/install.ps1`
- `hooks/guard.sh`
- `integrations/` and `templates/`
- Rule content that is incorrect in a way that weakens security
